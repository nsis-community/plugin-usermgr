## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-usermgr/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `UserMgr.dll` to `Plugins/<variant>/` and its headers to `Include/`.
